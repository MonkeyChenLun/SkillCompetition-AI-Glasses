# NoahVision（诺亚视界）—「耳蜗之眼」品牌 Logo 寓意、四套配色与开场动画解析

> **定稿方案**：「耳蜗之眼（The Cochlear Eye）」  
> **核心理念**：大道至简——**外面一笔螺旋耳蜗代表「听」，中间一点凝视瞳孔代表「看」**。不拼凑繁琐零件、不混杂多余颜色，每套方案仅使用一组相邻或互补的纯粹色彩。

---

## 一、 为什么最终定稿为「耳蜗之眼」？

1. **淘汰具象堆砌，回归“视听同源”本质**
   - 早期初稿曾尝试“写实人眼 + 12 片相机快门 + 字母 N”，在小尺寸下细节糊成一团且形如冷酷监控探头；中期探索过“方舟 + 18 片橄榄叶 + 五角星”，虽富叙事但叶片在 `16×16` 网页标签与眼镜端角标上仍偏细碎。
   - **终稿「耳蜗之眼」只用了两个最纯粹的几何母题**：
     - **外圈一笔阿基米德耳蜗螺旋（`COCHLEAR_SPIRAL_PATH`）**：从左侧外端起笔，顺时针旋入内圈，象征声波顺着耳蜗温柔旋聚，代表**「听（听觉辅助）」**；
     - **中心一点圆润瞳孔（`COCHLEAR_PUPIL`）**：稳稳落在螺旋包裹的视觉焦点，既是凝视世界的瞳仁，也是大洪水黑暗船舱中唯一发光的晶石之窗（*Tzohar*），代表**「看（视觉辅助）」**。
   - 远看是一只温和明亮的眼睛，细看是一枚拥抱瞳孔的耳蜗——**“以耳代眼，以眼听声”**的无障碍通感精神一眼即识，缩至 `16px` 依然清晰如初。

## 二、 四套标准配色体系（与控制台双主题严丝合缝）

| 方案代号 | 配色名称 | 核心色值 | 视觉意境与适用场景 |
| :--- | :--- | :--- | :--- |
| **A（浅色实装）** | **蓝到青** | `#1D4ED8` → `#14B8A6`（底 `#FFFFFF`） | 深蓝渐变到青绿，与控制台浅色主题同源：**深蓝是还没被照亮的世界，青绿是声音和光**。 |
| **B（深色实装）** | **夜里的蓝青** | `#3B82F6` → `#2DD4BF`（底 `#0E1A33`） | 同样的蓝青渐变放在深夜蓝底上，**像黑暗里亮起的光**，完美适配控制台深色琉璃主题。 |
| **C（印刷/高反差）** | **深蓝 + 一点青** | 螺旋 `#13265C` + 瞳孔 `#14B8A6`（底 `#FFFFFF`） | 螺旋采用沉稳深蓝，只有中心一点瞳孔亮起青绿：**整个耳蜗安静地托着一颗亮起来的瞳孔**。 |
| **D（人文暖调）** | **暖黑 + 琥珀** | 螺旋 `#F7EBD3` + 瞳孔 `#F0A23B`（底 `#1F1B16`） | 米白色螺旋配琥珀色瞳孔，落于暖黑底上，带有胶片与木质器物的温暖人文质感。 |

## 三、 纯代码 60fps「一笔绘耳蜗 · 瞳孔点睛」开场动画

- **代码位置**：`src/components/common/BrandIntro.tsx`、`src/components/common/brand-intro.css`
- **三幕叙事节奏（全程约 3.8 秒，4K 矢量零色带）**：
  1. **第一幕 ·「听」声波旋聚（0.1s ~ 1.7s）**：64 颗蓝青声光微粒沿螺旋轨道向中心汇聚，流光彗星沿耳蜗路径顺时针一笔绘出圆润螺旋；
  2. **第二幕 ·「看」瞳孔点睛（1.3s ~ 2.2s）**：螺旋收笔瞬间，中心瞳孔弹性点亮并激起一圈青绿虹膜光环与同心水波，演绎“黑暗里亮起的光”；
  3. **第三幕 · 品牌浮现与柔焦入场（1.6s ~ 3.85s）**：`NoahVision · 耳蜗之眼 · 听见万象 · 看见光芒` 伴随流光扫掠浮现，随后柔焦融入工作台（登录页单击左上角 Logo、或控制台内双击左上角 Logo 可随时重播）。
