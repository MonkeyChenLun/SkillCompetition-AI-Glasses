## 🎨 手绘初稿 01：《耳蜗之眼 Logo 推演与四套配色定稿手稿》
- **对应文件**：`手绘初稿01-耳蜗之眼Logo推演与四套配色手稿.png`
- **画面左边画了什么（三轮手稿淘汰与极简提纯记录）**：
  - **初稿 v1（红笔打叉淘汰）**：“写实眼睛 + 12 片相机快门 + 左眼角字母 N”。红笔批注淘汰原因：*“太像冷冰冰的安防监控探头！左眼角塞 N 重心偏斜，16px 下快门线糊成一团。”*
  - **过渡稿 v2（红笔批注做减法）**：“诺亚方舟 + 18 片对生橄榄叶 + 五角星”。批注：*“寓意虽满，但 18 片细叶在 16px 标签栏与眼镜端角标里仍显繁复——能不能用最少的一笔一画同时表达『听』与『看』？”*
  - **终稿定型 v3（蓝框高亮）**：提炼出 **「耳蜗之眼（The Cochlear Eye）」**——*“形状不变：外面一笔螺旋耳蜗代表『听』，中间一点圆润瞳孔代表『看』！每套只用一组相邻纯色，不再混杂四色！”*
- **画面右边画了什么（耳蜗之眼尺规作图稿 + 四套手绘配色卡）**：
  - 上半部在极坐标同心圆规辅助线与十字轴上，用双道彩铅手绘出阿基米德耳蜗螺旋（标出左侧 `190°` 圆头起笔 → 顺时针旋入 `398°` 收笔，线宽饱满均匀）与正中心 `(63.5, 64.1)` 处的点睛瞳孔；
  - 下半部并排手绘了 **A / B / C / D 四套配色方案小样与色卡标注**：
    - **A · 蓝到青**（`#1D4ED8` → `#14B8A6`，纯白底 `#FFFFFF`）：浅色工作台默认实装，深蓝是尚未照亮的世界，青绿是声音与光；
    - **B · 夜里的蓝青**（`#3B82F6` → `#2DD4BF`，深夜蓝 `#0E1A33`）：深色工作台默认实装，像黑夜里亮起的光；
    - **C · 深蓝 + 一点青**（`#13265C` + `#14B8A6`，纯白底）：耳蜗沉稳深蓝，安静托着一颗亮青瞳孔；
    - **D · 暖黑 + 琥珀**（`#F7EBD3` + `#F0A23B`，暖黑底 `#1F1B16`）：温润胶片感暖调备选。

## 🎨 手绘初稿 02：《整体工作台布局与动静双态玻璃草图》
- **对应文件**：`手绘初稿02-整体工作台布局与动静双态玻璃草图.png`
- **画面左边画了什么**：
  - 左侧内缩 `12px` 的**悬浮毛玻璃侧边栏**，左上角已嵌入新款 **「耳蜗之眼」** 品牌角标，下方将 9 个模块整理为「工作台」「数据与模型」「系统管理」三组，配连续滑动玻璃选中气泡；
  - 底部用红笔虚线框与向下箭头重点批注：*“★ 单窗口时自动下沉隐藏 Dock；多窗口向下滚动读表时也自动退让！”*
- **画面右边画了什么（静雾动透 Z 轴光学剖面）**：
  - **Top 业务卡片层**：`90%` 高不透明卡片，保证表格与多维图表清晰可读、零嵌套模糊开销；
  - **Mid 工作窗口外框层**：“静雾动透”双态切换——**静止时 `blur(26px)` 柔焦磨砂护眼，按住拖拽时化作 `blur(3px)` 清透水晶**，并配 2D 遮挡剔除与 3 窗 GPU 玻璃预算防闪屏；
  - **Base 水面点阵层**：2,150+ 颗硬杆锚定微光粒子 + 鼠标无框凸透镜光学放大。
