## 阶段一：V0.1.4 深度 UI 诊断与“减法改革”

### 1. 诊断痛点（UI 锐评总结）
在对 V0.1.4 的源码与运行截图进行全面审查后，定位出以下核心问题：
- **多窗口四分屏下的空间浪费**：每个分屏小窗口内都重复渲染了一个 `30px` 的页面 `<h1>` 大标题，与窗口自带标题栏重复，吃掉了近 1/4 的分屏可视高度，且窄窗口下数据表头被挤压成竖排折行。
- **底部 Dock 遮挡内容与导航冗余**：单窗口工作时，底部 Dock 与左侧导航栏完全重复，且悬浮压在页面底部卡片上遮挡文字。
- **凑数区块拉低信息密度**：「设备管理」页仅有 3 台演示设备，底部却放了一整块无交互的「设备管理内容」说明面板。
- **深色模式控件割裂**：权限抽屉中的原生下拉框（`.field-select`）与主按钮在深色主题下未融入毛玻璃胶囊体系。

### 2. 落地修复
- **单窗口单标题法则**（`src/styles/polish.css`）：在浮窗与四宫格分屏模式（`:not([data-mode="maximized"])`）下，视觉隐藏页面内部重复的 `<h1>`（保留读屏无障碍节点），同时加粗放大窗口标题栏文字；最大化模式下则隐藏标题栏标题，由页面大标题承载。
- **智能避让 Dock**（`src/components/workspace/Workspace.tsx`、`WorkspaceFrame.tsx`）：
  - 当仅打开 1 个未最小化窗口时，Dock 自动下沉隐藏（`data-hidden`），把底部留白归还给业务内容区；
  - 多窗口模式下监听 `.workspace-pane` 滚动方向，向下滚动阅读时 Dock 自动下沉退让（`data-collapsed`），向上滚动、悬停或切换窗口时自动浮出。
- **精简凑数面板与统一深色胶囊控件**（`src/pages/Devices/index.tsx`、`src/styles/polish.css`）：移除「设备管理内容」冗余面板；锁定窄窗口表头 `white-space: nowrap`；将 `.field-select` 与深色主按钮统一为高对比实心品牌蓝与毛玻璃胶囊。

## 阶段二：第一代动态背景与窗口液态果冻拖拽

### 1. 李萨如漂移背景与窗口搅动耦合
- 新建 `src/components/effects/LivingBackground.tsx` 与 `living-background.css`：6 组色彩光斑沿非周期李萨如（Lissajous）轨迹缓慢呼吸漂移，并叠加 SVG 微噪点（Film Grain）消除色带；
- 实现 `stirBackground()` 事件总线：拖动窗口时将指针速度矢量实时传递给背景光斑，产生流体卷吸（Fluid Entrainment）与弹簧回弹。

### 2. 窗口 3D 液态水动力形变与分屏倾倒动效
- 新建 `src/components/workspace/liquidDrag.ts` 并接入 `WorkspaceFrame.tsx`：
  - 拖拽窗口标题栏时，以抓取点为变换原点（`transform-origin`），窗口根据实时拖拽速度产生**横向剪切滞后（`skewX`）**、**纵向挤压拉伸（`scale`）**、**3D 俯仰/侧倾滑水姿态（`perspective(1150px) rotateX / rotateY`）** 以及**表面张力圆角动态形变（`border-radius`）**；
  - 松开鼠标瞬间，欠阻尼弹簧物理引擎接管（零 React 重渲染开销，直接驱动 DOM `transform`），窗口像一滴浓稠液体般晃动回稳；
  - 四角分屏吸附预览框加入液态水滴展开动画（`snap-pour`）与表面流光扫掠（`snap-shimmer`）。

## 阶段三：升级真·2D 浅水波动方程、WebGL 焦散折射与光学柔光蒙版

### 1. 实时 2D 浅水波动方程求解器（Isotropic 8-Neighbour Wave Solver）
- 在 `LivingBackground.tsx` 中引入 `Float32Array` 双缓冲高度场（`h0`, `h1`，约 11.5 万网格单元），以 60fps 求解各向同性 8 邻域二维波动方程（十字邻域权重 `0.20` + 对角邻域权重 `0.05`），彻底消除 4 邻域差分常见的棋盘格伪影，保证水波完美正圆扩散。
- **指尖开尔文尾波（Kelvin Wake）**：沿鼠标轨迹连续步进插值，注入前推波峰、后拉波谷的方向性核函数，划出逼真的 V 字形水波；并将水花半径精细收敛至 `8–15px`（点击水滴半径 `10px`），使涟漪细腻紧致。
- **WebGL 水下色散折射与焦散光网**：利用高度场梯度 $(n_x, n_y)$ 与拉普拉斯曲率 $\nabla^2 h$，在 Fragment Shader 中实现水底泳池焦散光网的斯涅尔折射弯曲、R/G/B 三通道微色散以及曲率透镜聚光。

### 2. 光学柔光消光蒙版与操作区域静默
- 新增 `.living-bg-veil`（径向工作区柔光暗角罩 + `16px` 微米级光学散射网点），并将遮罩中心不透明度精准调优至 `0.20~0.22`，既保留水面的通透感，又彻底消除刺眼白光；
- 将 Shader 高光从线性叠加（`col += ...`）改为柔和色调映射（`mix` + `clamp`）；
- 加入 `isOverConsoleContent()` 智能检测：当鼠标在表格、卡片、按钮内进行业务操作时，自动降低水波扰动强度，做到“动静得宜”。

## 阶段四：2,150+ 规整发光粒子点阵与“双层水玻璃”层级重构

### 1. 高密度规整光学粒子点阵（Precision Lattice）
- 将随机游离粒子升级为按 `22–28px` 等距正交网格整齐排列的 **2,150+ 颗发光微粒矩阵**，采用离屏预渲染三色发光精灵（Sprite Cache），60fps 绘制耗时低于 `0.3ms`。
- **鼠标轨迹破水水道**：鼠标划过时，通过线段最近点投影与叉积左右岸判定，将轨迹上的粒子整齐向左右两侧推开，犁出一条清晰的净空轨迹沟壑，两侧粒子堆叠并激发高亮荧光（Flare）。
- **3.5 倍准临界阻尼极速回弹**：将复位弹簧刚度提升至 `springK = 16.5`、阻尼系数提升至 `6.8`（阻尼比 $\zeta \approx 0.84$），粒子被划开后在 **0.45~0.8 秒内**迅速回流归位成规整点阵。

### 2. 双层水玻璃透视（解决粒子遮挡窗口与高斯模糊抹平粒子的矛盾）
- **物理层级归位**：将 `.living-particles` 与 `.living-water-film` 全部置于 `.living-bg`（`z-index: -1`）内部、消光蒙版 `.living-bg-veil` 之上，在物理层级上 **100% 位于所有工作窗口与卡片下方**；
- **两级玻璃分工**（`src/styles/polish.css`）：
  - **窗口外框底板（`.workspace-frame`）**：采用无模糊的水晶薄玻璃（`backdrop-filter: none` + `24%` 轻透底色），让窗口留白与卡片间隙处 100% 锐利透出底下的规整粒子点阵与划水轨迹；
  - **业务数据卡片（`.panel`, `.metric-card`, `.table-wrap`, `.assist-list`）**：各自拥有独立的 `blur(18px)` 与 `82%~88%` 磨砂底色，加上浅色模式高对比宝石蓝/亮白针尖光核设计，实现了“留白处颗粒分明、卡片内清爽护眼”的完美平衡。

## 阶段六：V0.1.8 动静双态玻璃（静置高斯模糊 / 拖拽清透）与浓稠液态物理调优

1. **动静双态工作窗口玻璃（解决静止阅读时背景略花的问题）**（`src/styles/polish.css`）：
   - **静止阅读态**：工作窗口底板（`.workspace-frame`）启用 **`blur(26px) saturate(1.75)` 高斯磨砂与 `66%~68%` 柔雾底色**，让底层的发光粒子点阵在窗口静止时自然柔化成柔和氛围光晕，完全不干扰数据阅读；
   - **拎起拖拽态（`[data-gesturing]` / `[data-liquid]`）**：抓取窗口拖动瞬间，窗口底板平滑过渡为 **近乎全透明的水晶玻璃（`blur(3px)` + `20%~22%` 极轻透底色）**，松手回稳后自动重新泛起高斯磨砂，兼顾了“静时极致清晰”与“动时视觉惊艳”。
2. **浓稠重液态粒子与水波物理（Viscous Thick-Liquid Physics）**（`src/components/effects/LivingBackground.tsx`）：
   - 增大粒子所受粘滞阻力（`drag = exp(-10.5 * dt)`，过阻尼回流无轻浮抖动）并扩大流体卷吸半径（`72–112px`）与前向拖拽分量；
   - 深化推动幅度（单颗最大偏移扩至 `±44px`）与波峰冲浪耦合力（`nx * 290 * dt`），并将 2D 浅水波迭代调整为更沉重的单子步高粘滞传播（`damping = 0.968`），呈现出浓稠液态玻璃/甘油般的厚重流动质感。
3. **版本同步升级至 `V0.1.8`**：
   - 全局版本号更新为 `UI V0.1.8`，同步生成 `ProjectUIv0.1.8` 目录并推送至 GitHub 仓库主分支。
